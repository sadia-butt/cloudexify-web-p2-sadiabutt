## Project Overview

Fashion Lab is a responsive e-commerce application developed using HTML, CSS, JavaScript, and Bootstrap. The project demonstrates front-end web development concepts such as responsive layouts, product filtering, shopping cart management, local storage, and checkout form validation.



## Features

- Responsive design for desktop, tablet, and mobile
- Product listing with images
- Product search functionality
- Category filtering
- Price filtering
- Product details modal
- Add to Cart functionality
- Remove items from cart
- Update product quantity
- Automatic cart total calculation
- Persistent shopping cart using Local Storage
- Checkout form with validation
- Stock management
- Countdown timer
- Bootstrap UI components
